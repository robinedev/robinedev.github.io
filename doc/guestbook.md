# Guestbook

Drop a hello, pitch a post idea, or leave some feedback.

Good things to leave here:

- a correction, if something on this site has gone out of date
- a post request, especially "I got stuck on X and found nothing useful"
- a war story about a fleet rollout that went sideways

Comments run on GitHub Discussions, so signing in with your GitHub
account lets you comment, react, and follow the thread. Please stick to
the [GitHub Terms of Service](https://docs.github.com/en/site-policy/github-terms/github-terms-of-service)
when posting.
